# TP16

Projet Java complet sur les annotations : annotations standard, annotations
personnalisées, annotations répétables, et système de validation par réflexion.

## Contenu du package `TP16`

25 fichiers `.java` regroupant toutes les étapes et exercices du TP (annotations,
processeurs, classes de test, validation...).

## Compilation et exécution

1. Importer les 25 fichiers dans le package `TP16` (dans Eclipse ou tout autre IDE).
2. Ajouter le fichier `config.properties` à la racine du dossier `src` (nécessaire
   pour `ConfigProcessor`).
3. Compiler le projet.
4. Exécuter n'importe laquelle des classes contenant une méthode `main` :
   `StandardAnnotationsDemo`, `AnnotatedClass`, `AnnotationProcessor`,
   `BuggyClass`, `LoggingInvocationHandler`, `SecurityProcessor`,
   `ConfigProcessor`, `ValidationTest`.
